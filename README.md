# CG Visualizer

A computational geometry visualizer and algorithm stepper built with C++ and Vulkan for Linux.

## Features
- Visualize computational geometry algorithms
- Step through algorithm execution
- Record and replay algorithm steps
- Interactive visualization of geometric data
- Vulkan-based rendering

## Tech Stack
- C++
- Vulkan
- Linux

## Status

Work in progress.

More algorithms, visualization features, and recording functionality will be added over time.
